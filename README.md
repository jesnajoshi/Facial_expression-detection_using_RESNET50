
# Facial Expression Detection using ResNet50

## Facial Emotion Recognition System

This project implements a facial emotion recognition system using ResNet50 deep learning architecture to detect and classify facial expressions.

## Features
- Real-time facial expression detection
- ResNet50-based deep learning model
- Support for multiple emotion classifications
- Jupyter Notebook implementation

See `requirements.txt` for dependencies.
